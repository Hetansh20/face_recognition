## Plain Text Version (for online forms / LinkedIn)

**AI-Powered College Attendance System** | 2025

Built a contactless face recognition attendance system deployed on the cloud, supporting a full college hierarchy (8 semesters, multiple classes and batches) with separate faculty and admin portals. Integrated InsightFace (ArcFace) for face embedding and YOLOv8 for multi-face detection in group photos. Features include timetable-aware session management, automated HTML email reports to faculty, low-attendance alerts to students, bulk student import via Excel/ZIP, analytics dashboard, and CSV export. Containerized with Docker and deployed on Railway.

**Technologies:** Python · Flask · InsightFace (ArcFace) · YOLOv8 · OpenCV · SQLite · Pandas · Bcrypt · Docker · Gunicorn · Railway
